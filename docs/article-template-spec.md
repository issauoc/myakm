# قالب المقالات `guide` — مواصفة التنفيذ لـ ChatGPT (2 نوفمبر 2026)

**الغرض:** مقال يُقرأ بسهولة، ويُقتبس منه بسهولة (بشرًا وآلات)، ومتوافق مع تحسين محركات البحث وAI Mode وGEO. يعمل عليه ChatGPT لإنشاء المقالات وإدخالها.
**المكان:** الثيم `189672751332` — الملفات: `templates/article.guide.json` و`sections/main-article-guide.liquid` و`assets/myakm-article-guide.css` و`.js`. لا يمس المقالات القديمة (687 مقالًا في مدونة Articles): يُفعَّل فقط حين يكون `templateSuffix = "guide"`.
**الحالة:** مسودة تنفيذ. لم تُجرَّب على المتجر الحي بعد (المعاينة تحتاج دخول مسؤول). لا يظهر القالب على الموقع الحي إلا عند نشر هذا الثيم بقرار المالك.

## 0) صفحة قسم المقالات (القائمة) — `blog.guide`
`templates/blog.guide.json` + `sections/main-blog-guide.liquid` + `assets/myakm-blog-guide.css`. عنوان ونص تمهيدي (يُعدَّل من محرر الثيم)، وفلاتر وسوم، وبطاقات (صورة، تصنيف، عنوان، مقتطف، كاتب، تاريخ، وقت قراءة)، وترقيم صفحات، وبيانات `CollectionPage` + `ItemList`. تُفعَّل بضبط `templateSuffix = "guide"` على المدونة نفسها عند نشر الثيم (لم يُضبط الآن حتى لا يتغير الموقع الحي).

## 1) ما يعرضه القالب (بالترتيب)
مسار التنقل ← العنوان H1 ← الكاتب والدور وتاريخ النشر وآخر مراجعة ووقت القراءة ← الصورة الرئيسية ← زر «لخّص لي المقال في ChatGPT» + زر «انسخ الاقتباس مع المصدر» ← **الإجابة السريعة** ← **أهم النقاط** ← **محتويات المقال** (تُبنى تلقائيًا من `<h2 id>`) ← نص المقال ← منتجات ذات صلة (من مجموعة) ← **أسئلة شائعة** ← **المصادر** ← بطاقة الكاتب ← أزرار ثانية ← اقرأ أيضًا ← التالي/السابق والتعليقات.
بيانات منظمة (JSON-LD) يولدها القالب: `BlogPosting` (+ `FAQPage` عند وجود أسئلة). `BreadcrumbList` من الثيم.

## 2) الحقول التي يملؤها ChatGPT
| الحقل | النوع | القاعدة |
|---|---|---|
| `title` | نص | يحمل الموضوع الرئيسي، ≤ 60 حرفًا ما أمكن، بلا حشو |
| `handle` | إنجليزي | أحرف صغيرة وشرطات من الموضوع |
| `author.name` | نص | اسم كاتب بشري حقيقي معتمد من المالك (لا «admin» ولا اسم المتجر) |
| `body` (HTML) | HTML | القسم 3 |
| `summary` | HTML/نص | وصف 120–155 حرفًا يصلح لنتيجة البحث |
| `tags` | قائمة | 2–5 وسوم موضوعية |
| `templateSuffix` | نص | `guide` |
| `isPublished` | منطقي | **`false` دائمًا** (النشر بأمر صريح من المالك) |
| `myakm_article.quick_answer` | نص متعدد الأسطر | إجابة مباشرة 40–60 كلمة تكفي وحدها لو اقتُبست |
| `myakm_article.key_takeaways` | list.single_line_text | 3–6 جمل قصيرة، كل واحدة مكتفية بذاتها |
| `myakm_article.faq` | json | `[{"q":"...","a":"..."}]` من 3 إلى 8، الجواب 30–60 كلمة |
| `myakm_article.sources` | json | `[{"title":"...","url":"https://..."}]` لكل معلومة رقمية أو فنية |
| `myakm_article.author_role` | نص | مثل «فني تركيب إكسسوارات سيارات» |
| `myakm_article.reviewed_by` | نص | اختياري، المراجع الفني |
| `myakm_article.last_reviewed` | تاريخ | تاريخ آخر مراجعة للحقائق (`YYYY-MM-DD`) |
| `myakm_article.cta_collection` | collection_reference | مجموعة المنتجات ذات الصلة (gid) |
| `myakm_article.article_type` | نص | `guide` أو `howto` أو `comparison` أو `faq` |
| `global.title_tag` / `global.description_tag` | نص | عنوان ووصف SEO إن اختلفا عن title/summary |

## 3) قواعد كتابة `body` (HTML)
1. **أول فقرة تجيب مباشرة** عن سؤال العنوان (جملتان)، ثم التفاصيل. لا مقدمات.
2. كل `<h2>` **يجب** أن يحمل `id` إنجليزيًا: `<h2 id="how-to-install">كيف أركّبها؟</h2>` (يعتمد عليها فهرس المحتويات). العناوين على شكل أسئلة أو عبارات تصف الجواب.
3. فقرات قصيرة (2–4 أسطر)، كل فقرة فكرة واحدة تُفهم وحدها. قوائم `<ul>/<ol>` للخطوات والمعايير، وجدول `<table>` للمقارنات.
4. كل رقم أو مقاس أو مدة أو سعر له مصدر في `sources`، أو يُصاغ كتقدير صريح. ممنوع اختراع مواصفة أو ضمان أو توافق أو بلد منشأ.
5. روابط داخلية لمنتجات ومجموعات المتجر (نص رابط وصفي، لا «اضغط هنا»)، وروابط خارجية قليلة لمصادر موثوقة.
6. صور: ملف حقيقي أو مُنشأ صادق، `alt` عربي وصفي، لا نص ترويجي على الصورة.
7. لا حشو كلمات مفتاحية، ولا فقرات مكررة بين المقالات، ولا نسخ من مواقع أخرى.
8. الطول يتبع الحاجة: ما يكفي للإجابة الكاملة (غالبًا 700–1500 كلمة للدليل).
9. لغة عربية واضحة، وكلمات المنتجات بأسمائها الوظيفية كما في المتجر.

## 4) الإنشاء (GraphQL)
`articleCreate(article: {blogId, title, handle, author:{name}, body, summary, tags, templateSuffix:"guide", isPublished:false, metafields:[...]})` — الحقول المخصصة تُمرَّر في `metafields` بالمساحة `myakm_article` والنوع كما في الجدول. مدونة المقالات: `gid://shopify/Blog/96530825444` (Articles).
بعد الإنشاء: اقرأ المقال والحقول من المتجر وقارنها، ولا تُعلن النجاح قبل ذلك.

## 5) ما هو مؤكد وما هو غير مؤكد (صدق)
- تحسين محركات البحث للذكاء الاصطناعي: توجيه Google (مايو 2025/2026) أن الأساس هو **محتوى مفيد أصلي وجودة تقنية وتجربة صفحة جيدة**، لا حيل خاصة. القالب يخدم ذلك (إجابة مباشرة، بنية واضحة، مصادر، كاتب، تواريخ، صور، سرعة).
- `FAQPage`: عرضه كنتيجة غنية في Google محدود لمعظم المواقع؛ نبقيه لأن الأسئلة نفسها تفيد القارئ والاقتباس.
- زر ChatGPT يفتح `https://chatgpt.com/?q=<نص+الرابط>&hints=search`. صيغة الرابط من سلوك معروف وليست واجهة موثقة رسميًا؛ تُختبر يدويًا بعد نشر الثيم.
- القالب لم يُرسَم على الموقع بعد؛ التحقق الأخير مراجعة شيفرة وقبول Shopify للملفات.

## 6) قبل النشر (بقرار المالك)
معاينة المقال التجريبي من لوحة التحكم على الجوال والكمبيوتر؛ فحص Rich Results Test؛ اختبار زر ChatGPT وزر النسخ؛ ثم نشر الثيم أو نقل الملفات للثيم الحي.
